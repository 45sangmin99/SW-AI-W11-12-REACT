`h('div', { key: id }, ...)` 또는 `h(Child, { key: id, ...props })`로 형제의
식별자를 지정합니다. `key`는 DOM 속성이나 자식 props에 전달되지 않습니다.
같은 key와 태그는 순서가 바뀌어도 같은 DOM 노드를 사용하며 props/text를 갱신합니다.
같은 key라도 태그가 바뀌면 해당 노드만 교체합니다.

key는 문자열 또는 유한한 숫자이며 형제 안에서 유일해야 합니다. 숫자 `1`과
문자열 `'1'`은 다릅니다. 중복·잘못된 key는 DOM 수정 전에 오류가 납니다.
key가 있는 함수형 자식은 DOM 노드 하나를 반환해야 합니다.

key가 없는 형제 목록은 기존 위치 비교를 유지합니다. 혼합 목록에서는 keyed
노드만 key로 연결하며, unkeyed 노드는 같은 절대 index의 unkeyed 노드끼리만
재사용합니다. 이동하는 목록의 모든 항목에는 안정적인 key를 지정하세요.

`diff`의 `CHILDREN` 변경은 기존 자식의 index snapshot과 새 VNode를 담습니다.
`patch`는 원래 DOM 대상을 먼저 확보하고 자식을 이동한 뒤 해당 대상의 내용을
갱신합니다. 제거·교체·unmount한 DOM의 이벤트 리스너는 정리합니다.
